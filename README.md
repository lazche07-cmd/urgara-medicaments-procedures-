# Repère SMUR

Application web indépendante pour consulter le catalogue public URG’Ara par thématique : 204 entrées, 22 thématiques, recherche, favoris locaux, historique et mode sombre.

Ouvrir index.html dans un navigateur. Les liens vers les documents officiels nécessitent Internet. Les dates sont celles affichées au catalogue lors de l’import du 21 octobre 2026 ; les mises à jour ne sont pas automatiques. Vérifier la version validée dans chaque document avant toute utilisation clinique.

## Mise en ligne

Dans Settings → Pages, sélectionner Deploy from a branch, puis main et / (root), et enregistrer. GitHub affiche l’adresse après le déploiement.

Aucune affiliation au BMPM ni à URG’Ara. Les protocoles restent accessibles sur leur site source ; ils ne sont pas réécrits.
